# Coddy - Conversational Data Analyst Agent

Coddy is a conversational data analyst agent that lets you analyze CSV files from Google Drive using plain English.

## Features
- Load CSV files via Google Drive shareable links
- Describe columns and data profiling
- Filter rows with safe evaluation
- Group-by aggregates (`mean`, `sum`, `count`, `min`, `max`)

## Installation & Quick Start
```bash
pip install -e .
python -m coddy
```
